# LogAgent 1.3.0 — ChatGPT Development Module

Adds an isolated Web UI development workspace.

Features:
- Project file browser
- File editor
- ChatGPT development chat
- Selected-file context
- Diff preview before applying changes
- Explicit Apply Change action
- Test execution through an allow-listed pytest entry point
- Change backups/history
- Development API
- OpenAI Responses API integration
- Server-side OPENAI_API_KEY only

The API key must never be placed in browser JavaScript. Configure it on the LogAgent server.
